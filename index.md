# Fitbit Health Sync

Fitbit Health Sync helps users auto-sync Fitbit / Google Health data to Apple Health.

## What it does

- Connects using Google OAuth (Google Health API). Existing Fitbit connections work until Google turns down the Fitbit Web API in September 2026; then you reconnect with Google.
- Reads selected health metrics: weight, body fat, steps, sleep, resting heart rate, active energy.
- Writes those metrics to Apple Health on this device.
- Supports periodic best-effort background syncing on iPhone.
- Health data is processed on-device. We do not operate a server that stores your health data.
